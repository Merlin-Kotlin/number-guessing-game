# Number Guessing Game 🎯

A simple number guessing game built with modern Android development practices.

## Features
- Built with Jetpack Compose
- ViewModel + StateFlow architecture
- Unidirectional Data Flow (UDF) pattern
- Survives screen rotation
- Clean separation of concerns

## Tech Stack
- Kotlin
- Jetpack Compose
- ViewModel
- StateFlow
- Material 3
